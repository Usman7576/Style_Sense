# Changelog

## [Unreleased] - Week 2 (classifiers, pre-training)

### Added
- `stylesense/metrics.py`: accuracy, macro-F1, confusion matrix, bootstrap 95% CIs, per-skin-tone (MST band)
  breakdown with worst-group gap.
- `stylesense/data/splits.py` + `scripts/make_splits.py`: dHash near-duplicate grouping and identity-aware
  stratified 70/15/15 splits; `scripts/download_datasets.py` + `configs/datasets.yaml`.
- Face shape: diamond rule from landmark ratios, grid-fitted rule classifier, logistic-regression and
  gradient-boosting baselines (`training/train_baselines.py`), `FaceShapeNet` (EfficientNet-B0 + geometry) and a
  two-stage resumable trainer (`training/train_face_shape.py`).
- Hair attributes: 4-head MobileNetV3 model with partial-label loss, label builder for Figaro-1k / CelebA / manual
  labels, resumable trainer and predictor.
- `stylesense/train_utils.py`: seeding, config overrides, atomic checkpoints, early stopping, CSV/W&B logging,
  augmentation including low-light.
- Kaggle notebook `notebooks/02_train_classifiers_kaggle.ipynb` (generated by `scripts/make_kaggle_notebook.py`)
  and `docs/kaggle_guide.md`.

### Changed (vs. plan)
- Gradient-boosting baseline uses scikit-learn `HistGradientBoostingClassifier` instead of LightGBM (one fewer
  dependency, same purpose).

### Fixed
- `.gitignore` rules for `data/` and `models/` also ignored `stylesense/data` and `stylesense/models`; now anchored
  to the repo root.

### Results
- Face-shape v0.1 trained on Kaggle (T4, ~20 min): test accuracy 0.838, macro-F1 0.836 [95% CI 0.809-0.861];
  best landmark-only baseline 0.597 val macro-F1. Target (>= 80% accuracy) met; Gate G1 passed.
  See `model_cards/face_shape_v0.1.md`.

### Not done yet
- Hair-attribute training (needs Figaro-1k / CelebAMask-HQ); commit `splits/face_shape.csv`; review square-class
  split balance; fairness evaluation (Week 6).

## Week 1

### Added
- Repository skeleton, `pyproject.toml`, ruff + pytest config, pre-commit hooks, GitHub Actions CI.
- `stylesense/landmarks.py`: MediaPipe Face Landmarker (478 points), head pose from the facial transformation
  matrix, 5-point similarity alignment to a 512x512 crop with room for hair and beard, 8 geometric face features.
- `stylesense/quality.py`: no-face, multiple-face, face-size, blur (contrast-normalised Laplacian), brightness and
  head-pose checks with user-facing messages.
- `scripts/check_photo.py`, `scripts/extract_features.py`, `scripts/download_models.py`.
- README, PRIVACY, consent form, data cards.

### Changed (vs. plan)
- Head pose uses MediaPipe's facial transformation matrix instead of solvePnP (more accurate, no 3D template needed).
- Blur score is contrast-normalised so dark-but-sharp photos are reported as dark, not blurry.
- Starting thresholds: blur 45, pitch 22 deg (MediaPipe reads ~10-15 deg on frontal faces). To be calibrated in W1 S3.
